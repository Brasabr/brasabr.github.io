## Como publicar no GitHub Pages

1. Entre na conta GitHub **Brasabr**.
2. Crie um repositório público com o nome exato `brasabr`.
3. Abra o repositório e escolha **Add file → Upload files**.
4. Envie todos os arquivos desta pasta, mantendo também a pasta `assets`.
5. Confirme em **Commit changes**.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**.
8. Selecione a branch `main`, pasta `/ (root)` e toque em **Save**.
9. Aguarde alguns minutos e abra https://brasabr.github.io/brasabr/.
